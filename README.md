# python-calculator

A simple command-line calculator built with python.

## Features

-Addition
-Subtraction
-Multiplication
-Division
-Handles divsion by zero erros

## Technologies Used

-Python 3

## How it works

The program displays a menu with four operations:

1. Addition
2. Subtraction
3. Multiplication
4. division

The user selects an operation, enters two numbers, and the calculator returns the result.

it the user tries to divide by zero, the program displays an error message.

## Project Structure

```bash
project.py
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/yamkelambewu08/python-calculator.git
```

2. Navigate to the project folder:

```bash
cd python-calculator
```

3. Run the program:

```bash
python project.py
```
